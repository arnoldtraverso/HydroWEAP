# HydroWEAP

Repositorio en R para la optimización del modelo hidrológico WEAP.
Este proyecto contiene scripts, funciones y herramientas desarrolladas en R para calibrar, analizar y mejorar el desempeño del modelo WEAP en estudios de gestión de recursos hídricos. Incluye métodos de optimización, análisis de sensibilidad, visualización de resultados y automatización de procesos.
